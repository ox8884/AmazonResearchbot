# 공개 소스 검사

로컬 실행 자료와 공개 소스를 분리한다. `.omo`, `.codex`, `data`, `apps/web/qa`, 실행 상태·검증 스냅샷, 환경 파일과 백업/개인키 파일은 공개 대상이 아니다. 제외 규칙은 파일을 삭제하지 않는다.

커밋 전에 실행:

```sh
node scripts/verify-publication-policy.mjs
node scripts/verify-source-publication.mjs --index
```

작업 중인 공개 후보 파일을 미리 확인하려면 `--worktree`를 사용한다. 기본값과 `--index`는 실제 Git index의 blob을 읽으므로, 스테이징 후 작업 파일을 고쳐도 이전에 담긴 비밀값을 놓치지 않는다. 검사 중 index가 바뀌면 실패한다.

검사 범위는 금지 경로, 대표적인 비밀키 형식, 로컬 `.env*`에 있는 8자 이상 비밀값·실제 계정 주소다. 파일 이름에 들어간 비밀값도 검사한다. 값 자체는 결과에 출력하지 않는다. 임시 테스트 저장소로 강제 추가와 staged/working 불일치를 검증한다.

이 검사는 모든 사업 데이터나 개인정보를 자동 판별하는 도구가 아니다. 전체 staged diff와 이미지·라이선스·문서의 공개 적합성 검토를 대신하지 않으며, 통과가 제품 전체 인수나 배포 승인을 뜻하지 않는다. `all`/야간·실서비스 인수는 별도의 기준을 따른다.
